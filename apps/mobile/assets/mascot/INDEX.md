# Mascote do Quibly

30 estados x 2 paletas = 60 arquivos.
`night` para o fundo escuro do app, `cream` para superficies claras e loja.

| Estado | Onde usar |
|---|---|
| `idle` | lista de aulas vazia / repouso |
| `wave` | boas-vindas do onboarding |
| `happy` | aula pronta |
| `celebrate` | subiu de nível |
| `trophy` | venceu a liga |
| `medal` | conquista desbloqueada |
| `crowned` | 1º lugar no ranking |
| `star` | quiz gabaritado |
| `streak` | marco de sequência |
| `xp` | ganhou XP |
| `listening` | gravando a aula |
| `headphones` | revisão em áudio |
| `thinking` | transcrevendo |
| `working` | gerando flashcards |
| `searching` | busca sem resultado |
| `reading` | estudando material |
| `graduate` | concluiu a matéria |
| `focused` | pomodoro rodando |
| `sleepy` | streak quebrada |
| `break` | pausa do pomodoro |
| `sad` | captura falhou |
| `worried` | nada encontrado no arquivo |
| `offline` | sem conexão |
| `locked` | cota atingida / paywall |
| `dizzy` | erro inesperado |
| `cool` | pro ativado |
| `wink` | dica / tooltip |
| `love` | pedido de avaliação |
| `surprised` | primeira captura |
| `cheer` | amigo entrou na liga |
